# Генератор и решатель лабиринтов

## Описание проекта

Проект представляет собой консольную программу для генерации лабиринтов и поиска пути в них. Программа способна генерировать лабиринты различной сложности и размеров, а также предоставляет несколько методов поиска пути от заданной точки А (начала) к точке Б (конца). Интерфейс приложения простой и понятный, с возможностью отрисовки в консоли лабиринта и найденного пути.

## Функциональные требования

-   **Генерация лабиринтов**: Реализовано 2 алгоритма для случайной генерации лабиринтов.
-   **Поиск пути**: Реализовано 2 алгоритма для поиска пути из заданной начальной точки А в конечную точку Б.
-   **Визуализация**: Печать лабиринта в консоль с точками старта и финиша, а также отображение найденного пути.
-   **Интерактивность**: Программа взаимодействует с пользователем через консольный текстовый интерфейс.

## Как запустить

1.  Скомпилируйте и запустите проект из вашей IDE. Точкой входа является класс, который создает экземпляр `GameSession` и вызывает его метод `run()`.
2.  Следуйте инструкциям в консоли:
    -   Введите высоту и ширину лабиринта.
    -   Введите координаты стартовой и финишной точек.
    -   Выберите алгоритм генерации из предложенных (`эллер`, `бэк трэкинг`).
    -   Программа сгенерирует и отобразит лабиринт.
    -   Выберите алгоритм поиска пути (`бэк трэкинг`, `поиск в ширину`).
    -   Программа найдет и отобразит путь в лабиринте.

## Реализованные алгоритмы

### Генерация лабиринтов

#### 1. Алгоритм Эллера (`EllerGenerator`)

Этот алгоритм генерирует лабиринт построчно.
-   Он проходит по каждой строке, помещая ячейки в множества.
-   Случайным образом решается, объединять ли соседние ячейки в одно множество (т.е. убирать стену между ними).
-   Затем создаются вертикальные соединения со следующей строкой. Каждое множество должно иметь хотя бы одно вертикальное соединение, чтобы избежать изолированных областей.
-   Последняя строка обрабатывается особым образом, чтобы гарантировать отсутствие замкнутых областей.

#### 2. Алгоритм с использованием бэктрекинга (`BackTrackingGenerator`)

Этот алгоритм основан на поиске в глубину (DFS).
1.  Выбирается начальная ячейка, она помечается как посещенная.
2.  Из текущей ячейки выбирается случайный непосещенный сосед, и стена между ними удаляется. Новая ячейка становится текущей.
3.  Если у текущей ячейки нет непосещенных соседей, происходит "возврат" (backtrack) к предыдущей ячейке по стеку.
4.  Процесс продолжается до тех пор, пока не будут посещены все ячейки.

### Поиск пути

#### 1. Алгоритм с использованием бэктрекинга (`BackTrackingSolver`)

Этот алгоритм также использует поиск в глубину для нахождения пути.
1.  Начальная клетка становится текущей и помещается в стек.
2.  Пока не найден выход и стек не пуст:
    -   Если у текущей клетки есть непосещенные соседи (не стены), один из них выбирается, текущая клетка заносится в стек, а выбранный сосед становится текущей клеткой.
    -   Если соседей нет, это тупик. Клетка извлекается из стека (бэктрекинг), и она становится текущей.
3.  Путь формируется из содержимого стека после достижения финишной клетки.

#### 2. Поиск в ширину (BFS) (`BFSSolver`)

Этот алгоритм исследует лабиринт "послойно" от начальной точки.
1.  Начальная клетка добавляется в очередь.
2.  Пока очередь не пуста:
    -   Клетка извлекается из начала очереди.
    -   Если это финиш — путь найден.
    -   Все непосещенные соседние клетки (проходы) добавляются в конец очереди и помечаются как посещенные.
3.  Этот метод гарантирует нахождение кратчайшего пути в лабиринте без взвешенных ребер.

## Структура проекта

Проект имеет следующую структуру пакетов:

-   `backend.academy`: Основной пакет.
    -   `generators`: Содержит классы-реализации алгоритмов генерации лабиринтов (`EllerGenerator`, `BackTrackingGenerator`).
    -   `solvers`: Содержит классы-реализации алгоритмов поиска пути (`BackTrackingSolver`, `BFSSolver`).
    -   `handlers`: Вспомогательные классы для обработки ввода (`InHandler`) и вывода (`OutHandler`) в консоль.
    -   `model`: Классы, описывающие сущности лабиринта (`Maze`, `Cell`, `Coordinate`).
    -   `GameSession`: Основной класс, управляющий логикой сессии игры.
